First pass (single-interface, post-boot):

    $ python3 tools/gale-sniff --duration 90
    [gale-sniff] iface 1 (AP). duration=90s. Ctrl-C to stop.

    coreboot-60d1b1c Mon Jan  9 00:04:49 UTC 2017 bootblock start
    [gale-sniff] captured 65 bytes

That capture only got the bootblock line because the script started AFTER
the puck had already booted. Most of the interesting output happens during
the first ~10 s.

Second pass with reconnect support (see full-boot.txt) captured the
complete vboot/depthcharge trace by starting the sniffer BEFORE the
power-on:

    $ tools/gale-sniff-all --wait --duration 120
    # then unplug+replug SuzyQ to power-cycle puck

Notes:
- Writes still time out -> CCD is locked, this is read-only.
- EC_PD (iface 0) only emits "RST EP0 NNNN" reset chatter.
- iface 3 (subclass 0x51) is silent during normal boot — likely the
  flashing / update endpoint.
- AP (iface 1) is where the real boot trace lives. See full-boot.txt.
